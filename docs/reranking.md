# 可选重排序实测

本页为虚构制度上的原始实验。新增的 50 个片段、30 题公开 FastAPI 文档实验见 [真实公开文档评测](public-evaluation.md)，包含多证据覆盖回退与等价证据漏标的分析。

运行时间（UTC）：2026-10-17T19:03:16.875332+00:00。共 16 份虚构制度、16 个片段，本次 60 题，分组选择 `all`。

## 方法

三种检索方式分别比较原始排名与重排序排名；每组共用同一个临时索引，未修改应用知识库，也未调用生成 API。
原始方式直接取前 5 条；重排序先召回最多 10 条，用 Cross Encoder 比较问题与片段，再取前 5 条；从结果计算 K=[1, 3, 5]。
使用现有题目、参考文件名和原文证据。全部证据命中率要求每条证据都在前 K 条；MRR 仅表示第一条相关证据的排名，无答案题不计入这两个指标。
另外统计候选池的完整证据覆盖，帮助区分“候选缺失”和“排序未排进前 K”。重排序只能调整候选池内的顺序。
三组各预热一次，按每题先关闭、再开启的顺序串行测量；包含检索和适用时的重排序，排除模型加载；没有测并发性能。
各分组表的耗时列统一显示全部所选题目的中位数，且对应实际取前 5 条的请求，不是单独测量 K=1 或 K=3 的请求。
本次参数在评测前确定，未按结果调参。dev 用于诊断；test 题目已在先前报告展示，不能视为全新盲测。

## 边界

这份报告只测检索，没有重新测量生成回答。不能把检索命中率当成问答准确率或幻觉率。
无答案题仍可能召回片段；重排序未实现证据充分性判断，不能保证模型正确拒答。
片段短、资料少，Top-5 覆盖相对容易；单次时间受设备负载影响。是否开启应结合 dev 的证据覆盖、排序和额外耗时判断，保留关闭选项。
