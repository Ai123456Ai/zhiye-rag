每次请求独立取 Top-3；重排序：False；规则：`rules_round_robin_v1`。
开关两组共用同一个临时索引，最终来源数上限相同；拆解组额外运行子问题检索，按子问题轮流取证据，再由原问题补充，按片段 ID 去重。启用重排序时对每个查询分别重排后合并。
这是“分句检索加轮流合并”整体的比较，无法把收益单独归因于拆句或合并策略。原检索候选参数相同，但拆解组计算次数更多，不能声称计算预算相同。
本次只测本地检索，不调用生成 API，也不测回答完整率、拒答或幻觉；应用知识库未用于评测。

## 方法与限制

规则只按明确标点和连接词处理最多三个子句；不做语义改写、不补齐省略主语，也不理解跨子句条件。短句、过多子句、来源数少于子问题数时回退原问题。反引号和引号中的分隔符不用于拆句。条件、比较或指代复杂时可能拆错，仍需人工核对展示的子问题。
先用既有公开题的 dev 做诊断，再固定另一个题集的新问法运行；新问法共享六篇原文及部分既有概念，由同一项目编写，不是独立用户数据或外部盲测。没有按本次 test 结果再次调参。
每题每组只测一次，轮流先开/先关，排除预热和模型加载；没有测并发或波动区间。并列排名仍受片段随机 ID 影响；同次开关对比共用索引，但重建索引后结果可能变化。
候选顺序与检索/重排序分数分别保留；轮流合并后的总顺序不是按跨查询原始分数排序，这些分数都不是答案置信度。去重只按片段 ID，不把跨文档相同文本合并丢失来源。
拆解默认关闭。尤其来源数较少时，分配给一个子问题的名额可能挤走另一条证据；既有版本筛选和歧义拦截仍执行，额外检索不等于证据充分性校验。
